
# 📦 DeliveryNow – Smart Parcel Delivery

A modern parcel delivery booking and tracking web application built using Python and Streamlit.

## Features

- Schedule parcel deliveries
- Choose preferred delivery dates and times
- Automatic delivery price estimation
- Unique parcel tracking IDs
- Booking history
- Admin dashboard
- Delivery status management
- CSV report export
- SQLite database

## Technologies Used

- Python
- Streamlit
- SQLite
- Pandas
- Custom CSS

## Installation

Clone the repository:

    git clone YOUR_GITHUB_REPOSITORY_URL

Move into the project:

    cd DeliveryNow

Create virtual environment:

    python -m venv venv

Activate on Windows:

    venv\Scripts\activate

Install requirements:

    pip install -r requirements.txt

Run the application:

    streamlit run app.py

This project demonstrates Python application development,
database management, UI design, data handling and deployment.
